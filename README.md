# 狗狗管理平台 v2.1

一套能跑起来的养狗记录系统。档案、喂养排便计划、训练、饮食健康、周报、日记、记账、
知识库与联网检索，全部做成真能点的页面，支持手机安装（PWA）。

**技术栈**：Flask + SQLite + Bootstrap 5 + Chart.js（静态资源全本地化，断网也能用）
**生产服务器**：waitress（8 线程，比 Flask 自带的开发服务器稳）

**座右铭**：技术改变工作，设计美化生活

## 一、怎么跑起来

| 步骤 | 操作 |
|---|---|
| 1 | 双击 `安装.bat`（只在第一次做，装 Flask/requests/bs4/Pillow/waitress） |
| 2 | 双击 `启动服务.bat` |
| 3 | 浏览器自动打开 `http://127.0.0.1:5800`（已开自启的话，开机就自动起，这步可跳过） |

启动后地址也会写进 `data/访问地址.txt`，黑窗口/日志在 `data/server.log`。

手机打卡：手机连同一个 WiFi，用 `data/访问地址.txt` 里的**局域网地址**（比如 `http://192.168.1.10:5800`）打开。
**Windows 防火墙第一次会弹窗，要点「允许」**。

| 脚本 | 作用 |
|---|---|
| `安装.bat` | 建虚拟环境 + 装依赖 |
| `启动服务.bat` | 启动服务（已在跑就不重复起）、打开浏览器 |
| `停止服务.bat` | 关掉 5800 端口上的服务进程 |
| `开机自启-开启.bat` | 把平台加进 Windows 启动项，以后开机自动起 |
| `开机自启-关闭.bat` | 取消开机自启 |
| `deploy_local.py` | 命令行版：`start` / `stop` / `status` / `restart` |
| `install_autostart.py` | 开机自启的底层实现：`on` / `off` / `status` |
| `reset.py` | 清空狗狗和记录（知识库保留） |
| `reset.py all` | 连知识库一起重建 |
| `seed_demo.py` | 重新灌演示数据 |
| `selftest.py` | 自检：跑一遍所有页面、接口和联网检索（跑在临时库+临时上传目录上，不碰真实数据） |
| `e2e_check.py` | 端到端验证：对着**正在跑的服务**发真实 HTTP 请求（含文件上传），测完自动回收，净零改动 |
| `make_icons.py` | 重新生成 PWA 图标 |

## 三、联网检索入库（知识库模块的自动化）

入口：导航「联网检索」，流程四步：

```
① 搜关键词（双引擎：Bing + 百度，自动合并去重 + 相关性过滤）
      ↓
② 结果按信源可信度排序（可信 / 中等 / 偏低 / 未知），勾选想看的
      ↓
③ 系统抓正文（最多 6 篇，每篇间隔 0.4 秒），按规则提取候选条目
      ↓
④ 你逐条确认 → 入库。入库的每条都带来源域名和原文链接
```

| 特性 | 说明 |
|---|---|
| 信源分级 | 兽医学院/科研科普/官方 = 可信；垂直宠物媒体 = 中等；自媒体/问答 = 偏低 |
| 相关性过滤 | 搜索结果与关键词完全无关的直接挡掉（Bing 偶尔返回无关结果） |
| 反爬站点处理 | 知乎/公众号/小红书等直接灰掉标「不可抓」，提示手动打开后手工入库 |
| 直接抓网址 | 支持粘贴任意文章链接直接提取，绕过搜索 |
| 重复拦截 | 入库时按结论全文查重，重复自动跳过 |
| 分类归档 | 按 喂养/免疫/排泄/训练/饮食/行为/健康 自动分类 |

## 四之二、狗狗状态（不是「在养 / 已归档」这种二值开关）

养狗的实际情况比「在不在档」复杂。现在用**五个状态**描述：

| 状态 | 含义 | 影响 |
|---|---|---|
| **在养** | 当前正在饲养 | 正常排计划、打卡、发提醒（默认） |
| **送人** | 已送养 / 转让 | 档案保留，**不再提醒**喂养免疫训练 |
| **死亡** | 已离世 | 档案保留，不再提醒 |
| **走失** | 走失未找回 | 档案保留，不再提醒 |
| **其他** | 其他情况（寄养在外等） | 档案保留，不再提醒 |

**怎么改**：档案列表每行的「改状态」按钮，或工作台右上角「改状态」，或在编辑档案页里改。

**变更会留痕**：每次状态**真的变了**，系统自动记一条
「原状态 → 新状态 + 变更说明 + 时间」，在「🗂 档案与免疫」页的「🔁 状态变更历史」里能翻。
状态没变不会写记录（重复保存不会刷出一堆垃圾流水）。

**总览页**：只展示「在养」的狗狗卡片；非在养的收在页面底部的「📦 非在养狗狗」里，
点进去还能看历史、改回「在养」。

**筛选**：档案列表顶部有「全部 / 在养 / 送人 / 死亡 / 走失 / 其他」标签，点一下只看这一类。

## 四之三、父母信息

编辑档案页第 ④ 栏，记录**父犬 / 母犬**各自的名字、犬种、芯片号（血统号），外加一条血统备注
（血统证书号、同窝只数、父母有无遗传病史等）。这些在「🗂 档案与免疫」页展示。

用途：判断遗传病风险、预估成年体型，转送或就医时说明来历。

## 四之四、记录怎么改、怎么删、存在哪

**训练、喂食、排泄、体重、饮水、备注** —— 六类记录统一在「记录管理」页管理。

| 操作 | 怎么用 |
|---|---|
| 打卡 | 今日待办点「打卡」，或记录管理页右上角四个按钮 |
| 编辑 | 任何一条记录右侧点「编辑」→ 弹窗会带出原值 → 改完点「保存修改」 |
| 删除 | 记录右侧点「删除」（会二次确认） |
| 筛选 | 按类型 / 日期范围 / 关键词（内容、备注）筛；还有「今天/近7天/近30天」快捷按钮 |
| 翻页 | 每页 50 条，最新在前 |

能改的字段：**日期、时间、类型、内容、备注**。训练记录还能改项目、环境、干扰等级、成功/总次数、奖励、下次调整；
排泄能改定点成败、便便评分、地点、触发点、是否带血；喂食能改投喂量、吃完量、主食、零食、补充剂。

**数据存在哪**：全部存在**运行服务的那台电脑**上 —— `data/dogplat.db` 一个 SQLite 文件。
手机只是打开网页，数据不落在手机上。备份就是复制这一个文件。

**几个自动联动**（不是坑，是设计）：
- 体重记录改了或删了，档案里的「当前体重」会自动取**最新那条体重记录**，不会出现档案和记录打架。
- 编辑时可以把记录类型都改掉（比如把误记的「饮水」改成「喂食」），联动逻辑一样会跑。

## 四之五、🐶 狗狗日记（图文 / 视频）

工作台标签「📖 狗狗日记」。一篇日记 = 日期 + 标题 + 心情 + 地点 + 正文 + 若干图片/视频。

| 操作 | 怎么用 |
|---|---|
| 写日记 | 右上角「✍️ 写日记」→ 填内容 → 选照片/视频（可多选）→ 保存 |
| 看照片 | 点缩略图放大到原图（新窗口） |
| 看视频 | 卡片里直接播放（`<video>` 控件，不自动加载省流量） |
| 编辑 | 日记卡片右上「编辑」→ 改文字/日期/心情/地点 |
| 删附件 | 每个附件右上角 ✕（文件从硬盘一并删除） |
| 删日记 | 卡片右上「删除」→ 连同附件一起删（二次确认） |
| 筛选 | 按月份下拉 + 关键词（标题/正文/地点）；每页 20 篇 |

**支持格式**：图片 `jpg / png / gif / webp / bmp`；视频 `mp4 / webm / mov / m4v`。
**单次上限 300MB**（放得下一段手机短视频），超了会有明确提示。

**文件存哪**：`data/uploads/diary/<狗狗id>/<年月>/`，文件名用随机串（原始中文名另存在库里，页面照常显示）。
图片会自动生成缩略图（最长边 640px），所以日记列表滑起来很快。
访问走 `/media/...` 路由按需读取，不塞进 static。

**备份**：日记的**文字在 `dogplat.db` 里**，**图片视频在 `data/uploads/` 目录里**。整机备份要**两个都复制**。

## 六、部署与自启（本机/局域网）

平台跑在自己电脑上，不依赖任何云服务。

| 环节 | 怎么做的 |
|---|---|
| 服务进程 | `pythonw.exe app.py`，无黑窗口后台跑；用 waitress 8 线程扛并发 |
| 日志 | stdout/stderr 全部 tee 到 `data/server.log`，出问题先看这个文件 |
| 访问地址 | 启动时把本机地址和局域网地址写进 `data/访问地址.txt` |
| 开机自启 | 在「启动」文件夹写一个 VBS，开机后等 15 秒再拉起服务（避开开机争抢） |
| 手动启停 | `启动服务.bat` / `停止服务.bat`，或 `deploy_local.py start|stop|status` |

开启自启：双击 `开机自启-开启.bat`，看到「已开启」即可。之后重启电脑不用管，平台自己起。

> 说明：`开机自启-开启.bat` 在**你自己电脑上**有效。若在没有图形界面/受限的环境（如某些沙箱）里，
> 系统会拦掉启动项写入，属正常现象——换到真实 Windows 桌面执行即可。

## 九、已知边界（如实说）

1. **联网检索抓不到反爬站点**：知乎、微信公众号、小红书、抖音、B 站等有严格风控，
   系统明确标灰并提示手动打开。能稳定抓取的是科普中国、兽医学院、宠物医院站、
   品牌官网、垂直宠物站。
2. **搜索质量依赖公开搜索页**：没有付费搜索 API，走的是 Bing/百度公开页面，
   偶尔返回无关或过期结果，已用相关性过滤 + 信源分级兜底，但不是 100% 干净。
3. **提取的是段落不是语义摘要**：没有接大模型，候选条目是按规则筛出来的原句，
   最后一道关是人工确认。
4. **PWA 断网只能看不能记**：打卡走 POST 请求，离线会提示失败，数据不会丢因为根本没发出。
5. **未做登录鉴权**：设计前提是单机/家庭局域网。局域网内任何人都能访问，别把它暴露到公网。
6. **iOS 添加到主屏幕无自动安装条**：这是 iOS 的限制，需手动走分享菜单。
7. **防火墙要放行**：手机连不上，十有八九是 Windows 防火墙挡了 5800 端口，第一次启动时点「允许」即可。
8. **开机自启需真实桌面**：自启靠写 Windows「启动」文件夹实现，必须在正常登录的 Windows 桌面上才生效。
